A zero-account browser chat room mimicking mid-90s online services.

The state runs on Upstash Redis and is shared across three different frontends (React/Vite deployed on Vercel):

* The standalone chat interface (https://lolchat.rip)

* A Windows 95 simulator (https://56k.rip)

* A Mac System 7 simulator (https://dialup.rip)

Users dialing in from the Mac desktop and users on the Win95 machine end up in the exact same rooms talking to each other.
