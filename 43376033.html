Thanks for that rec. I looked at the repo and saw it hasn't been updated for 5+ years[0]. There's a Register article about it from a few months ago[1]. There's a fork with some updates done in the last few months[2]. Claude Code summarizes the changes as:

  1. Update to modern Linux & cleanup & simplify (66c1b9798)
    - Upgraded from Linux 5.6.8 to Linux 6.10.14
    - Updated Alpine Linux from 3.11.6 to 3.21.0
    - Added essential system utilities (LVM, cryptsetup, e2fsprogs, etc.)
    - Simplified build scripts and improved organization
    - Removed unnecessary components to streamline the system
  2. Remove outdated script (3dfaeb7ad)
    - Removed an obsolete chroot script that was no longer needed
  3. Add tools, add ZFS support, autologin as root (4e7b1f4bf)
    - Added OpenZFS 2.3.0-rc3 support
    - Implemented automatic root login for easier access
    - Added more system utilities including debootstrap
    - Set hostname to "onerecovery"
    - Improved network configuration
  4. Optimize for size (f2a2ae4d5)
    - Removed unnecessary packages to reduce the final file size
    - Adjusted ZFS build process to be more efficient
    - Optimized build parameters for better size constraints
    - Commented out unused utilities to keep the image lean

  These improvements collectively modernize the system, add significant functionality like ZFS support, optimize the size, and make it more user-friendly with auto-login while maintaining the core concept of a single-file Linux distribution.

  [0] https://github.com/zhovner/OneFileLinux/
  [1] https://www.theregister.com/2024/09/09/onefilelinux_esp_distro/
  [2] https://github.com/D4rk4/OneRecovery
