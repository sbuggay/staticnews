It looks bloated as hell because it allocates all kinds of RAM pages it doesn't really use in case it needs to JIT extensively (which usually get compressed or swapped out anyway), but by default it's a decent UI framework.

Tauri takes what, maybe 50MiB of RAM? It's not the most efficient way, but it's as efficient as a usable cross-platform framework gets these days. Telegram is written in native Qt and takes about 1750MiB of RAM on my machine to show me a chat screen. The framework isn't the issue here.
