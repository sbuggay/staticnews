Companies are ever more willing (and more crucially: getting away with; even in the EU), running software without proper privilege separation. If data is accidentally accessible, send out the "we value your privacy" mail and keep going. At the same time developers are less slowed down from deploying to insufficiently abstracted/unified target systems: If they do run into problems that could have been completely avoided with something like docker, LLM will reduce the cost of diagnostics. And then there is the diminishing appeal of having docker compose together all the required libraries. Which is not needed, if all the libraries are statically bundled into one huge binary, as has become precariously customary.
