For anyone who might not know, parts of it did forcefully and successfully escape containment. Core Mac Toolbox APIs originally created for Star Trek (like the portable C implementation of QuickDraw 2D) were installed on hundreds of millions of PCs as QTML, which QuickTime for Windows was built on, which was in turn a requirement for iTunes for Windows. QTML on Rhapsody was also the PoC for Carbon for Mac OS X, with ClarisWorks as the guinea pig.

Mac OS 7 “Virtual Memory” was just the swap file. Fundamentally classic Mac OS had a flat memory layout with special hooks defined that did not allow for virtual memory as more commonly defined.
