I have the Epson EcoTank Photo ET-8550 printer and have found it to be excellent for printing photos. It prints up to A3+ size (13" x 19") and ink costs are low since it uses tanks, which can be refilled using ink bottles, vs cartridges. The main caveat is that it uses dye inks which theoretically don't have the longevity of pigment inks, but for my purposes (family photos and photo club competitions) it doesn't matter.

Keith Cooper on YouTube has lots of informative videos about the ET-8550: https://www.youtube.com/@KeithCooper/search?query=8550
