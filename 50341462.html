"default deny incoming" would apply to the filter INPUT chain, and there are several other chains that run before that one (raw, conntrack, mangle, nat), so it's better to use an explicit iptables or nft rule targeting the earliest "raw PREROUTING" chain.

Do note that eBPF can still bypass netfilter entirely, as can containers, or any process using a separate network namespace.
