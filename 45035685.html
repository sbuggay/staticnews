The Transputer as an implementation has failed, but all modern server/workstation CPUs, starting with some later models of the DEC Alpha, followed by AMD Athlon and then by all others have followed the Transputer model of organizing the CPU interfaces.

Unlike the contemporaneous CPUs and many later CPUs, the Transputer had 3 main interfaces: a memory interface connecting memory to the internal memory controller, a peripheral interface and a communication interface for other CPUs.

The same is true for the modern server/workstation CPUs, which have a memory interface, PCIe for peripherals and a proprietary communication interface for the inter-socket links.

By inheriting designers from DEC Alpha, AMD has adopted this interface organization early, while Intel, like always, has been the latest in adopting it, by they were forced to do this eventually (in Nehalem), because their obsolete server CPU interfaces reduced too much the performance.

The Jupiter Ace was unreal, but only from a computer science perspective. You had to know a lot to know how to program Forth which was the fundamental language of that white but Spectrum-looking dish of a PC, in spite of a manual that read like HGTTG.
