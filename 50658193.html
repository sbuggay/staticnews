This is an addon for BlenderUI, which has apparently been decoupled from Blender:

(Edit: decoupled by same author, not by Blender.)

https://github.com/ppmpreetham/BUI

The readme says it supports dear imgui API, tkinter, html and js (including react etc), Qt syntax, Rust, Lua ... that's a lot!

Also seems to support the browser via wasm, though it might be a bit heavy for that.
