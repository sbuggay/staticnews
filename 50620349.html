pcthrowaway|root|parent|next|

With a mail server it actually might be a problem for some companies.

AGPL means that (on top of GPL terms) companies must provide modifications to anyone using the software over the network.

Now typically companies are exempt from having to distribute source changes to GPL or AGPL software, if they're using it internally.

But because it's a mailserver that can presumably send or receive mail to external users, if a company ever modified the Stalwart source, they'd presumably have to find a way to distribute that to every person that sends an email to or receives an email from a Stalwart mailserver.

I have no idea how this would be done though, and I'm pretty sure it's completely untested so far. Both whether inter-mailserver communication counts as use that would trigger the AGPL "access over a network" clause, and what method of notifying the mailservers (and perhaps users) it communicates with would satisfy the "making the source available" requirement.
