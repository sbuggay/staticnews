I'm building ShopSpec (https://shopspec.io/) for this kind of workflow. I'm a woodworker and use it for my own home and shop builds.

It's narrower than Shapr3D, but it might fit the projects you describe.

I learned OpensCAD manually but it was so painful because you needed to take into account the most minimal and ridiculous thing using code, so I used Freecad in the end that is way more intuitive and fast with graphical tools.

bob1029|prev|next|

Be aware that AI is really bad at certain kinds of geometry. This can either go very well or very poorly. I'm not aware of many happy cases in the middle.

A simple test is that if the object you are modeling could be described by a brief python program (automating blender/CAD APIs), then the LLM will probably one shot it perfectly. If what you are modeling is a human face or bird, then the LLM is at best a clumsy apprentice. High Kolmogorov complexity is the common thread behind all things that LLMs will struggle with.

It can sometimes be easier to lean on a diffusion model and then trace over the results the old fashioned way. Diffusion completely sidesteps the geometry which helps with design speed.


janne-alatalo|prev|next|

I've tested different ways to use agents to model stuff from images with accuracy. Maybe this is something that can help or give you ideas: https://janne-alatalo.fi/en/articles/silhouette-modeling/

If you have some physical reference, for example a coffee table, you can create an accurate 3D model of that quickly. The agent creates model that can be converted to STEP format and opened with any CAD software.

This might help you? You get a good model that you can start editing towards your own design.

Here is agent skill that works with OpenAI models and Codex https://github.com/janne-alatalo/image-to-cad-skill

Basically you take few pictures. Three is usually enough of furnitures. The agent uses the pictures to find the exact camera poses and creates a 3D model that minimizes the difference between the object's silhouette in images and in the 3D-model when projected with the virtual cameras to the 2D planes. The agents create the model with python scripts. First using numpy for faster optimization and finally CadQuery for easy exports to CAD formats.

90 deg corners... Get a square that you trust. Learn the 3-4-5 method.

patience.

Wear hearing protection.

You more than likely will probably never need a table saw, jointer or a festool domino tool.

Tools I'd get first:

- japanese pull saws

- good chisel set

- a track saw... and a 2.4x1m.2m sheet of foam to cut on

- a palm router, learn how to make all your own jigs

- 12 irwin quick clamps. if you also prefer and can afford, 12 t-track f clamps.

- an impact dril, and a normal drill

- a decking drillbit

- a marking guage

- pencils

- a speed square

then

- make or get saw horses. and 2.4mx1.2m sheet of formply

100% avoid:

- 90 corner clamps.

  instead get larger 1.2m irwin quick clamps or 3d print some corner protectors for a strap (assuming you're doing boxes)

itissid|prev|next|

I do home improvement projects (I've in wall built-in storage, benches and nooks) I am on a clock and i have very little room in which to work. The only tool I have relied on https://www.cutlistoptimizer.com/ I have found that the CAD based tools to be pretty much beside the point for _most_ wood working projects for hobbyists, for a few reasons:

1. First several 3-d design iterations are throwaway reworked because I am constantly measuring the design, clearances and studs. And paper works best here instead of working with clankers which takes way longer.

2. Choosing the right kind of materials: thickness and type of plywood, type of hinges, panels, finished or unfinished. Optimize for simplicity of putting components together is most important.

3. Once the design settles the actual joinery needs to be as simple and efficient e.g. butt joints work well most of the time. A good jig for pocket holes is generally the most needed. You will be surprised how well a staple gun works for creating back panels of cupboards.

Its not that they are not useful, shopspec looks great(good job variodot), its just that I can get further and faster without them for most hobbyist pursuits. I invoke YAGNI most of the time because I constantly ask myself one question: "How can I make this be less time consuming?".


Jemm|prev|next|

RapidCAM.app (https://rapidcam.app) has excellent support for AI. The file format specs are published and open source so AI can easily write an ".rcam" file.

RapidCAM.app is a parametric 2.5D CAD/CAM for CNC and laser with support for rotary axis. RapidCAM.app runs in the browser or as desktop apps. There is no login required. The app is free to use. Privacy is respected. rcamhub.com is the sharing site for .rcam files.

Within the App, you can define your project and then use the built in prompt generator. This creates a prompt with all the details AI could need. Once the AI replies with the file, you can paste it back into the app which will then verify the file for you.

Desktop versions of the app have MCP server built in so AI can control the app directly if that is a route you prefer.

I started RapidCAM for my own use as I found that the CNC was sitting idle simply because firing up a full CAD/CAM package took too long. The idea with RapidCAM is that you can quickly sketch out your job from as simple as you need to as advanced as you want going from unconstrained to full parametric/constrained as required.
