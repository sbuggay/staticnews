con|prev|next|

Hi HN and สวัสดีครับ! I remember seeing this the first time in Vienna by a friend of mine, Michi who came back from NYC and I believe he learned about it at the local hacker space at the time: NYC resistor.

I knew Michi through the Metalab, our hacker space in Vienna. Originally the idea seems to have been from the Graffiti Research Lab, which is also what I've linked to on my page and in the repo's Readme.

I think the version that Michi used was a MacOS app (not sure which framework), but I've always wanted to make it a web app. So all you need now is a projector, a laser pointer, and a laptop (with a camera).

I've already tried a few fun setups (eg using the iPhone's camera or using AirPlay connected to the projector). It's quite flexible.

Let me know if you end up using it and please share videos / photos and I'd be happy to put them up.

I know the original is old-skool cool, which I think makes this a fun project.

I'll try to set it up at the next CCC (2027) - if you see me there, come say Hi (I'll probably be in a banana costume).
