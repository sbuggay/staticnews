amluto|prev|next|

> Depth-wise cross-attention (split Q/K/V): While standard transformer attention operates across tokens in a sequence, DCA applies attention across layers in depth. Each token queries a dynamically weighted mix of all prior layer embeddings, unlocking the model's full historical context without the computational penalty usually required to scale traditional attention.

I’ve often thought that something like this might lead to a real solution to the infamous strawberry problem.

Ignoring pesky issues like tokenization, the actual input data is visible to the model as the embedding fed to the first layer, but the first layer is probably nowhere near smart enough to understand that the model is trying to count R instances. But by the time whatever layer is reached that might understand the goal, the non-wasteful part of the low-level memory (the K’s and V’s from the first layer) can’t be queried any more.

But this cross-depth attention can query them!

Admittedly, there are holes in this argument. Beyond just tokenization (to the extent that the model can see letters at all, it is reconstructing them), the attention mechanism doesn’t really have a clean “count the hits” operation.
