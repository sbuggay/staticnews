sidkshatriya|root|parent|prev|next|

> The upgrade mechanism from 7.9 to 8.0 is still gloriously simple, and exactly the same as it has been for many years

The upgrade mechanism on a typical Linux distribution is _even more_ gloriously simple, and exactly the same as it has been for many years.

  # Fedora/RHEL
  $ sudo dnf upgrade -y

  # Debian/Ubuntu
  $ sudo apt update && sudo apt upgrade -y

  # Arch Linux
  $ sudo pacman -Syu
The false distinction between the OS packages and user local (/usr/local) packages during upgrade causes much unneeded complexity. FreeBSD is making this go away which is welcome.

But yes you are correct, if you want to upgrade a Ubuntu distribution like 26.04 you do need to issue a command like `sudo apt dist-upgrade` which is admittedly an additional command.
