Even `expires_in` requires care. The token expires in 3600s, but, from when? In the token there will be an `exp` with an absolute value, but `expires_in` in the envelope is relative -- relative to when? Relative to whenever the issuer issued the token, so relative to `iat`/`exp`. But you don't want to have to extract that from the token, and you won't get to if the token is encrypted, so the best you can do is add `expires_in` to now, but it has to be a clock value from before you send the request.
