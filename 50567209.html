QuantumNomad_|root|parent|next|

WireGuard is also very much like SSH private keys.

A basic config to set up a VPN that only adds access to services on the VPN itself is very short and simple, both for WireGuard server and for WireGuard clients.

You can run the WireGuard server from your home computer. For example on your NAS machine itself or some other machine you have at home. And open the port for WireGuard to the outside.

Also some routers can run WireGuard server on the router. For example Mikrotik routers have WireGuard server built in and ready to configure [0]. Routers running OpenWrt can too [1].

Or you can rent a small VPS and use that as your WireGuard server.

And then, any which where you run the WireGuard server, run the WireGuard client on your laptops, iOS and Android devices, and connect client apps using VPN internal IP addresses. And your NAS etc too, if the WireGuard server isn’t running on the NAS machine itself.

It really is quite quick to set up with server and all clients across devices.

The only real hurdle is that on iOS you have to turn the VPN back on manually after reboot and which is sometimes easily forgotten if you only use your self hosted services occasionally. But you quickly realize oh right I have to open the WireGuard app and turn on the VPN again whenever you try to use one of your self hosted services and the client isn’t connecting.

[0]: https://manual.mikrotik.com/docs/virtual-private-networks/wi...

[1]: https://openwrt.org/docs/guide-user/services/vpn/wireguard/b...
