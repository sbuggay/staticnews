Sigh.

This came up during the original "Les Kelly vs. Arriba Soft Corp." case in 2002[1] which was about the legality of "linking" on a web page.

The bottom line is that answering DNS queries, just like placing links on a web page, is protected speech.

If you doubt this:

It's easy to describe an (absurd) methodology of storing DNS records as human readable directions, in the form of anecdotes or sentences, which could then be parsed by a simple reader.

This is the reductio ad absurdum that I proposed in my public email exchange with Les Kelly[2] regarding the case:

"The idea that a web browser could simply read human english text descriptions of a pictures location on a web site, and then display it as if it were an inline link, is not that unbelievable."

... and the same is true with the DNS.

In 2026 it would be a trivial project to create a "DNS server" whose records were human readable, english statements and a client who could query them with similar.

After all these years, do I really have to create this ?
