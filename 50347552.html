For all of the ciw examples, ce is easier since the cursor is at the first letter of the word.

Where dw works, this game teaches vlllld instead, which is a bad habit to teach.

Ctrl+A increments the first number after the cursor, which is easier than, say, f6r7 in cases where they do the same thing. Similarly, Ctrl+X decrements.

t:t: is weird when fY is much easier.

The Vim simulator has a minor difference compared to real Vim:

    0
    0
Start on line one and do CTRL-V then j then CTRL-A. Real Vim would increment both. The simulator only increments the one under the cursor.
