kimixa|parent|prev|next|

One limitation of the stack is that it needs to be contiguous virtual addresses, so it was often limited when devices just didn't have the virtual address space to "waste" on a large stack for every thread in a process.

But 64 bits of virtual address space is large enough that you can keep the stacks far enough apart they even for pretty extreme numbers of threads you'll run out of physical memory before they start clashing. So you can always just allocate more physical pages to the stack as needed, similar to the heap.

I don't know if the .net runtime actually does this, though.
