It can do basic arithmetic because it's fed millions or billions of synthetic calculations as training data.

Quick!

What's the next top-k tokens after each of these?

"999 + 999 = "

"999.0 + 999.0 = "

"999 * 2 = "

"999 * (3-2) = "

Mathematically identical. But as a token sequence, not so much.

Modern models will of course have very similar next-token distributions across all of these. But not identical!

Now add a few digits and you quickly land in territory whose synthetic training data is much sparser.

Code has determinism and runs in milliseconds. It's the better tool for the job.
