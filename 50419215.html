Yes, security is difficult, but there are some simple rules that you don't need to be a security expert in order to adhere to (I'm definitely not one myself, I'm just a garden variety dev), and that these guys did not follow, in particular:

- Never hard-code credentials (especially in front-end exposed code)

- Never share credentials between environments (especially between prod and non-prod)
