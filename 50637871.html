adrian_b|parent|next|

The existence of one-way functions (Rank 008 in TFA) would have a tremendous importance for cryptography.

For now, all cryptography is based on using functions that are supposed to be one-way from the secret key to the encrypted text, but nobody knows whether this supposition is true. From time to time, some functions that were assumed to be one-way are proven to not be such functions.

Knowing to use functions that are provable to be one-time, instead of making random choices while hoping that they are correct, would be the greatest change in cryptography since its invention millennia ago.

If we had a mathematical method to prove that a function is one-way, that would have immediate consequences, as everyone would switch ASAP to use ciphers based on such functions.

To be useful, any solution to this problem must include either a criterion for deciding whether a function is one-way or a method for constructing such functions.
