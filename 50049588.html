SaarthRanka|parent|next|

Thanks! I believe I can add Deepseek support pretty easily. Atticus runs on Claude Code, and Claude Code can point to any server that uses Claude's API. DeepSeek has one so I added a Custom server option in Settings > Intelligence > Custom server. Put in https://api.deepseek.com/anthropic, your DeepSeek key, and deepseek-chat as the model. Same thing works for Ollama or LM Studio.

One thing is that DeepSeek's API doesn't take images, so anything where Atticus has to look at your screen won't work on it. Opening apps, music, web stuff, and shell commands are fine. I'll push this in an upcoming update.
