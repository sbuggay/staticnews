I'm currently running an iPod Nano 7G (the touchscreen one that looks like a very small phone). It has Bluetooth, no clip and I think it is amazing.

The 7g and the 6g (the little square one with the clip) have the advantage of supporting rewind (2 clicks, hold) and fast-forward (1 click, hold) via headphone remote, which is a killer feature for my use cases, especially for audio books using the m4b format.

However, if anyone is looking for a more modern alternative, you could give the HiBy R1 a try. Unfortunately it is a bit bigger in size, but it can be purchased new, has decent audio quality, has a full Linux and there is an Open Source player attempt called Sonix Player written in C, which is very promising and pretty much taking of right now:

https://github.com/Tartarus6/sonix-player/
