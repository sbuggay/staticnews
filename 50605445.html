I don't think this will make any sense in the long run--say, five years from now.

Even short-term it doesn't handle the mixed cases: 10% of a program is vibe coded, the rest is at varying levels from mostly AI-written to AI-checked to mostly human-written. That's the reality for my code, anyway.

I think, in the future, the provenance of something, whether code or writing or art, is only going to matter to a small percentage of people. Most of the world only cares about the result: does the code work? Is the writing worth reading? Is the art beautiful? A badge isn't going to change the answer.

We're in a transitional period where we haven't collectively agreed on how good AI is. If we all believe AI code is as good or better than humans (like compiler code today) then we don't need a badge. If we all believe that AI code sucks compared to human code, then we also don't need a badge, because no one will let AI write code.

The transition will end once we land on a consensus--though, to be fair, the consensus might change over time as AI changes.
