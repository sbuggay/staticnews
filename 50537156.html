The composability of jQuery has been an inspiration for the way I design my own frameworks and tools.

One thing I still regularly use jQuery for, though, that's rarely mentioned, is its event model. You can put a listener on any object, not just things in the DOM. Any data object can trigger an event. This is incredibly powerful for isolating logic from DOM elements and events. A frequent use case is for DOM elements to contain a reference to a data object that may be replicated elsewhere on the page. The data object sets up and tears down visual elements, listening for interaction, then dispatches a custom event. Your core logic listens for events on the data object instead of on every individual element that might refer to it. I usually delegate the draw routine for e.g. html snippets of a card or an interactive element to the data object itself in a draw() function that returns a string which incidentally jQuery handles quite nicely inserting into the DOM without needing to explicitly call createElement.

I wrote my own implementation of this a long time ago, but in the end, that feature plus the other ergonomics of jQuery still make it my go-to today over vanilla js. And pretty much everything I write is without any reactive framework (other than my own vanilla component/templating/remoting system), so the overhead is barely noticeable.

Those original AJAX API's were pretty slick, but not well understood at the time. Surprisingly they could stream characters! The response is partially available each time onprogress fires:

  const xhr = new XMLHttpRequest();
  let lastLength = 0;

  xhr.addEventListener("progress", () => {
    const chunk = xhr.responseText.substring(lastLength);
    
    lastLength = xhr.responseText.length;

    console.log("New data:", chunk);
  });

  xhr.open("GET", "/stream");
  xhr.send();
-------------------

The modern fetch API is better though because it's a Promises API and it can stream as raw bytes, not characters:

  const response = await fetch("/stream");
  const reader = response.body.getReader();

  while (true) {
    const { value, done } = await reader.read(); 

    if (done) {    
        console.log("Finished");
        break;
    }

    console.log("Received", value.length, "bytes");
  }
