anthk|parent|prev|next|

Gemini it's good on legacy machines and some clients can be really barebones (awk+less), and for some security there are clients written in Go. For awk+less, do yourself a favour. Run

    unset LESSOPEN
or have it at ~/.profile.

Reticulum it's unusable in 32 bit machines, it badly needs a Go port for nomadnet.

On Gopher, well, lynx/sacc and maybe i2pd for some security and anonimity.

As a start, there's:

     gopher://magical.fish
     gopher://sdf.org
For gemini,

     gemini://gemi.dev it's nice.
'Lagrange' covers both gemini and gopher as a client.

You can set an HTTPS proxy for it and read news sites and blogs over Gemini.

Just set

     stargate.gemi.dev:1994
As the HTTP proxy in the settings for Lagrange.

For the terminal guys, there's Telescope and it can use HTTP proxies as well. Read the man page.
