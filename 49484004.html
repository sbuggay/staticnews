I refer to Exactitude quite often, but more often to highlight that the code isn't the documentation, to use the same analogy.

When we make a map, it is a purposeful abstraction. It disregards some things and exaggerates others. The map cannot explain everything – to do so it would need to be exactly the same size as the land beneath it.

When you make a map, document code, present or listen to an argument etc. you need to focus on what's important for this specific purpose. Otherwise your map will be useless. Either from being incomplete, of from being too complete.
