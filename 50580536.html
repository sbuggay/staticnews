Someone compiled an x86 port of Valve's Lepton compatibility layer, its still a work in progress but is working for a few Android utility apps that I wanted on Linux.

I'd argue Lepton is potentially better than waydroid due to:

- podman containers, so no root required

- no awkward file permission issues

- per-app lepton containers are possible, for additional sandboxing

Its definitely still a WIP though, needs more refinement and improvements before I'd consider recommending it to regular nontechnical users.

https://github.com/pjohno/lepton-x86_64

Yeah, I'm surprised at how well its working for my handful of Android apps right now.

In my opinion, one of the biggest limitations right now is that it requires Steam as a dependency because it uses the same `Steam Play` compatibility infrastructure as Proton.

lepton shows up as another option in the compatibility tools dropdown in Steam, so you can use different versions of lepton for different apps too. So one day, we can maybe see something like Proton GE but for Android apps.

But it should be possible to eventually break that steam dependency, umu-launcher already does it for Proton-based gaming.
