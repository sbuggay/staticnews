If I understand you correctly, #1 is just plain wrong. JSX is transformed into standard ECMAScript[0]. You can store JSX-nodes in variables and pass them around however you like.

  // this
  <Box>
    {
      shouldShowAnswer(user)
        ? <Answer value={false}>no</Answer>
        : <Box.Comment>
            Text Content
          </Box.Comment>
    }
  </Box>

  // ...can be written like this
  const answer = (
    <Answer value={false}>
      no
    </Answer>
  );
  const comment = (
    <Box.Comment>
      Text Content
    </Box.Comment>
  );
  const result = shouldShowAnswer(user) ? answer : comment;

  <Box>
    {result}
  </Box>
In React at least, null won't render anything.
