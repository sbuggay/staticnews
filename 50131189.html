The challenge is is getting the peripherals emulation detailed enough to be useful - and in reality it'll never be good enough to completely replace physical hardware because you're trying to clone a buggy black box whose API is only vaguely documented.

But if it's just an approximation anyways, why not save yourself an awful lot of time and emulate the HAL a few layers up for the 95% of logic which doesn't require the actual hardware?

Just like in software, your cloud web app doesn't need a cycle-accurate emulation of the entire Amazon cloud. Mocking a few REST calls is often more than enough, and in practice mocking the SDK API has basically the same result.
