I've used various combinations of Codex, Claude Code, GitHub Copilot, Figma's MCP, Figma Agent, Pen.dev, and Paper.design for product design. I have previous experience with front-end dev so I'm more technical than the average product designer.

In my experience, Figma Agent and Figma's MCP leave something to be desired. I'm sure Figma Agent is useful for people who haven't used Claude Code or similar before, but it really requires most of your product's context to exist in Figma for it to do well.

As soon as your product's context exists out of Figma, then it starts to drift and hallucinate its own styles. Using the MCP with an AI that has access to your code provides better results, but even it will have trouble remembering what page I'm asking it to edit.

I know they're trying to address this by adding features such as guidelines and specs, along with linking your Figma files to GitHub repos, but my complaint with these features is a lot of the companies I have worked for do not use the very specific tech stack that Figma supports with these features.
