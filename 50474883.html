taylorfinley|parent|next|

Weights start as random values generated from a seed. Pytorch uses however many cores are available on the architecture to write out the initial values in parallel, so each seed + architecture pair has a particular signature. If I understand Will's technique correctly he's basically made a rainbow table of initial weight states. Training alters the initial weights, but if you find one seed + architecture pair that vastly more-closely matches the trained weights, you can infer it must have been the source of the initial weights.

Distillation might shape the weights similarly in some way to the source model, but that would come from the signal, not the noise. I think it would be very surprising if the initial untrained weights were encoded with any fidelity into the outputs such that training another randomly-initialized set of weights (likely of completely different size and shape) on them could leave a signature of the source model's initial state, does that make sense?
