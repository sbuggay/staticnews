hypertexthero|parent|next|

Solution: Edit the # Print the current date section in…

  /Users/$USER/Library/Application Support/espanso/match/base.yml
…to read:

  # Print the current date
  - trigger: ":date"
    replace: "{{mydate}}"
    vars:
      - name: mydate
        type: date
        params:
          format: "%Y-%m-%d"
