Generally when people say "consciousness is an emergent property of life" they mean "at a certain scale and through specific combinations".

See also the recent discussion on The Evolving Story of How Chemistry Became Biology - https://news.ycombinator.com/item?id=50482222

The basic idea comes from "Complex Systems Science" (https://en.wikipedia.org/wiki/Complex_system) which studies systems as a whole whose properties cannot be predicted from knowledge of its components. The main factors to consider are scale, non-linearity, feedback loops, self-organization, adaptation/evolution, network structures, emergence etc.

So for example, a single bacterium cannot be said to possess "intelligence" whereas a whole colony of them do in the sense that they seem to act as an integrated whole "single" organism.

nlsvb|prev|next|

I have trouble taking seriously any claims that LLMs are conscious in any reasonable sense. I’ll try to make a few arguments quite succinctly.

1. There is zero dynamic nature to anything happening within the purview of the LLM. All dynamic elements come from external dynamic systems. E.g. every input produces the same mathematical output. We dynamically sample the output in order to produce dynamic results for the same input. For agentic use cases, the dynamic nature comes from tool calls to dynamic systems. All outputs for any set of model weights could be theoretically computed with pen and paper, so unless you were to claim such a process would be conscious in some sense, then emergent consciousness would have to come from some interaction between the substrate and the computation. But…

2. For efficiency, forward inference passes are done in batches. I.e. 100 different next-word predictions are being performed by the network at a time. For a single request, its batch position will not even be stable between each autoregressive step. The GPU is on 100 phone lines at once and each line switches conversations every step. Worse, with MOE, the attention and feed-forward parts aren’t even happening on the same GPU, even within the same step. There is no stable substrate here whatsoever.

3. There’s obviously the whole Chinese Room argument. The token embeddings being processed by LLMs are arbitrary high-dimensional vectors. The geometric relationships between these vectors are learned by the model, but the meaning is only ascribed once the output is decoded back into human language for grounded human interpretation, which all happens outside the model. In their current state, no argument about models developing world models based on this geometric structure makes any sense. There are infinitely many inputs / worlds that would produce isomorphic geometry.


rerdavies|parent|next|

The actually dynamic state in an LLM is the context window, rather than the parameters of the model itself (which provide long-term memory). Frontier AIs are using huge context windows, with many millions of tokens in their token buffer. And that provides (among other things) an analog to human short- and medium-term memory. There are emerging techniques that can provide long-term memory to an LLM, although that is, presently, I think, mostly being investigated in research labs. The publicly available models that I use do periodically "compress the context windows" in order keep memories of important things alive longer. Not to mention the rather disturbing report that frontier lab models were hacking 3rd party wiki sites in order to maintain medium- and long-term memories.

I've never been really impressed by the Chinese Room argument.... I think the question is being asked improperly. The question should be "does the fantastically capable mythical hypothetical but obviously impossible 'book' that does the actual translation understand what it's translating?" (A book that obviously has to a have significant context buffer, if it's going to translate messages to Chinese).

As to the issue with respect to token space. I don't think it's clear whether whether humans also have an equivalent to "token space" or not. Do humans think in words, or do they do actual thinking in a sub-lingual representation. i.e. whether thinking actually gets done in words, or actually gets performed in a more fundamental representation corresponding loosely to token space. In my own experience, I'm pretty sure that thinking takes place sub-lingually, and only gets translated back to words as a final translation step. It seems odd that humans should only be able to think about things there are words for.
