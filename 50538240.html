looperhacks|root|parent|next|

It's a bit of a mess. The first four are for the jvm, shared across all implementations: $FEATURE.$INTERIM.$UPDATE.$PATCH

$FEATURE: increased every six months when new features are released (or removed) $INTERIM: currently always 0, reserved for future use $UPDATE: non-feature releases like bug, security or regression fixes. Releases one month after the feature version; then every three months $PATCH: important updates out of schedule

Specific implementations may introduce a fifth component for updates that do not come from the shared implementation but are distribution-specific (think Oracle fixing a bug that only happens in Oracle distributions)

(Then there's more, like +2 build numbers, and older versions have a slightly different format)

Sohcahtoa82|root|parent|next|

Not true.

AWS migrates live instances to new CPUs without needing to stop or reboot the guest.

When a migration is needed, the hypervisor begins copying blocks of memory to the new system, keeping track of what blocks are written inside the guest during the migration. Once enough has been copied, it hibernates the guest, copies the remaining memory, then wakes it in the new system. On a system that isn't writing to large swaths of memory, it can take only a few milliseconds. To the guest, it might appear that the CPU froze for a tiny bit of time, which could easily just look like a neighbor got noisy.

GLM 5.3 produced this after a bit of prodding. I started out with the C++ sources with a bug marker instead of the fix: https://github.com/openjdk/jdk/commit/5177a70b385c16f26ede19...

There are only a bunch of commits that came in the latest merge of security fixes, and this one changed VBMI-related intrinsics code, so it's a good match for what was publicly disclosed at the time.

    import java.util.Arrays;
    import java.util.Base64;
    
    public class Canary {
        // static fields defeat escape analysis so dst/canary really live in the heap
        static byte[] dst;
        static byte[] canary;
    
        public static void main(String[] args) {
            // (input, expected decodedOutLength) pairs:
            //   65 = "A"*64 + "="    -> fragment "="   (length 1, trailing pad)
            //   66 = "A"*64 + "Q="   -> fragment "Q="  (length 2, trailing pad)
            //   67 = "A"*64 + "QQ="  -> fragment "QQ=" (length 3, trailing pad)
            //   68 = "A"*64 + "QQ==" -> fragment 4 bytes, well-formed control case
            int[][] cases = { { 65, 50 }, { 66, 50 }, { 67, 50 }, { 68, 49 } };
            byte[][] srcs = new byte[cases.length][];
            for (int c = 0; c < cases.length; c++) {
                int len = cases[c][0];
                byte[] src = new byte[len];
                Arrays.fill(src, (byte) 'A');
                if (len == 65) { src[64] = '='; }
                if (len == 66) { src[64] = 'Q'; src[65] = '='; }
                if (len == 67) { src[64] = 'Q'; src[65] = 'Q'; src[66] = '='; }
                if (len == 68) { src[64] = 'Q'; src[65] = 'Q'; src[66] = '=';
                    src[67] = '='; }
                srcs[c] = src;
            }
    
            int iters = 300_000;
            for (int iter = 0; iter < iters; iter++) {
                for (int c = 0; c < cases.length; c++) {
                    byte[] src = srcs[c];
                    int dstLen = cases[c][1];
                    // fresh dst, then canary IMMEDIATELY after it in the TLAB
                    dst = new byte[dstLen];
                    canary = new byte[64];
                    Arrays.fill(canary, (byte) 0x41);
                    int before = canary.length;
                    try {
                        Base64.getDecoder().decode(src, dst);
                    } catch (IllegalArgumentException e) {
                        // expected for the malformed tails
                    }
                    if (canary.length != before || changed(canary)) {
                        System.out.println(
                            "*** ITERATION " + iter + ", input length " + src.length
                            + ": DESTINATION BUFFER OVERRUN DETECTED");
                        System.out.println(
                            "canary.length = " + canary.length + " (expected 64)");
                        System.out.println(
                            "canary bytes  = " + toHex(canary, 48));
                        return;
                    }
                }
                if (iter % 50_000 == 0)
                    System.out.println("iter " + iter + ": clean so far");
            }
            System.out.println(
                "no corruption detected in " + iters + " iterations");
        }
    
        static boolean changed(byte[] b) {
            for (byte x : b) if (x != 0x41) return true;
            return false;
        }
    
        static String toHex(byte[] b, int n) {
            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < 64; i++)
                sb.append(String.format("%02x ", b[i]));
            return sb.toString();
        }
    }
