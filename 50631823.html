_spduchamp|prev|next|

If you want an entire computerized pedal-board, checkout PiPedal. (https://github.com/rerdavies/pipedal) Can run on an RPi5 headless and you control it with tablet or phone or web browser. I opted to run on more powerful machine to have it boot the UI using kiosk mode Chromium.

For my setup I repurposed an old Intel NUC with DietPi and PiPedal on it, added a cheap wide touchscreen and a used audio interface to create my audio cyberdeck. You can see what that rig looks like here: https://github.com/rerdavies/pipedal/discussions/590

PiPedal has really nice integration with Tone3000, so their whole library of NAM and impulse responses for convolution reverbs is at your fingertips.

I built it to use with my Electroduochord, but I'm having way more fun playing Solarpedals (solar panels with audio jacks) and pulses from an infrared remote control. https://youtu.be/idcLP2TqPIA
