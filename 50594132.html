I guess it is if you haven’t worked with this sort of thing before

pcap is a file format for packer captures. You can use tools to capture copies of all packets traversing a network interface, both on clients and servers running operating systems like Linux and Windows, and on network switches and routers that support this (at a minimum, with enterprise gear you can at least send a copy of all traffic from specific source and destination interfaces in both receive and transmit directions to other interfaces you connect a “sniffer” to that you then run a pcap capture on, or you can often even encapsulate the copied traffic in GRE tunnel payloads and send them directly to a remote sniffer).

This is a local web app that uses Python libraries to analyze these capture files and look for common tell tale signs of specific issues, such as a TCP connection being opened and being immediately reset, which is an excellent way to find firewalls in the path that are denying connections. You can also, providing an API key, send the capture and analysis result to an LLM to discuss things further.

A sufficiently talented network engineer can do this by hand, but can save time with this tool. End users that aren’t capable of interpreting the capture due to lack of knowledge of underlying network protocols can also get results this way without escalation.
